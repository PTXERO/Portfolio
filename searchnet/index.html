Logins & analysis

Reading from a browser only works while that browser is fully closed (Windows locks the cookie file while it runs, you'll see "Permission denied … Cookies"). If you'd rather keep it open, export a cookies.txt with a browser extension such as "Get cookies.txt LOCALLY" and put its path above.

Cookies are read on the computer, so this means a browser on the computer where you're logged in. X, Instagram and some others need a login. Use a spare account: heavy scraping can get accounts limited and breaks those sites' terms. Keep it personal.

Run it

One command sets up everything: it installs or updates Python, Git and ffmpeg, downloads or updates SEARCH//NET, installs the packages, and starts it. Run the same thing again any time to update.

# Windows: paste into PowerShell
irm https://ptxero.neocities.org/searchnet/install.txt | iex
# after the first time: double-click searchnet\start.cmd

# Mac / Linux: paste into Terminal
curl -fsSL https://ptxero.neocities.org/searchnet/install-sh.txt | bash
# after the first time: bash ~/Portfolio/searchnet/start.sh

Leave that window open. Then scan the QR code on this page with your iPhone (same Wi-Fi). In Firefox on iPhone: ⋯ → Share → Add to Home Screen to use it like an app.
