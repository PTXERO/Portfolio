RUN LOCALLY

Collecting and downloading runs on your own computer through a small Python server (standard library only). The page you're looking at connects to it automatically.

# 1. required: the downloaders
pip install -U yt-dlp gallery-dl
# 2. optional: search inside videos
pip install faster-whisper          # speech → text
# + install ffmpeg and tesseract     # thumbnails, on-screen text
# 3. start it (from the portfolio folder) and open the printed link
python reel-vault/server/reelvault.py

X needs a login for search, timelines and bookmarks. Set a cookies source below (export a cookies.txt from your browser, or read cookies straight from an installed browser). A secondary account is safer: heavy scraping can get an account rate-limited, and it is against X's terms of service. Keep collections for personal use and respect creators' rights.
