YOUR OWN WORKER LATEST v1.3

You probably don't need this page any more. SEARCH//NET now fetches through PTXERO's shared hub by default (nothing to deploy; fair-use daily limits), and the hub guide is the way to run your own hub with no limits, which also carries Social and ASCII//RENDER. This page remains for a bare SearchNet-only Worker: fetching only, no identity, no backups.

The Worker is a tiny fetcher that runs in your Cloudflare account, for free. The app (in your browser) asks it for posts; it fetches from open APIs and hands them back. It stores nothing and logs nothing — your library stays in your browser. Setting it up takes about five minutes, once.

⬇ DOWNLOAD .JS You'll paste this in step 4.
1

Make a free Cloudflare account

Go to dash.cloudflare.com/sign-up. Email + password, confirm the email. No card, no domain needed — the free plan gives 100,000 Worker requests a day, far more than this needs.

2

Create a Worker

In the dashboard's left menu open Compute (Workers) → Workers & Pages (on some accounts it's just Workers & Pages). Press Create, stay on the Workers tab and choose Start with Hello World!

Name it searchnet and press Deploy. The first time, Cloudflare asks you to pick a workers.dev subdomain — any name; it becomes part of your Worker's address.

If your dashboard looks different: any route that ends in an empty "Hello World" Worker is fine. What matters is step 4.

3

Open the code editor

On the page that appears after deploying, press Edit code (top right). You'll see a file called worker.js (or index.js) with a few lines of Hello World.

4

Replace the code and deploy

Click into the editor, select everything (Ctrl+A / ⌘+A), delete it, and paste the code you copied above. Press Deploy (top right) and confirm.

Paste the whole file — it starts with a comment block and ends with a small "Node test shim". The editor may warn about module on the last lines; that's fine, it's ignored on Cloudflare.

5

Copy your Worker's address

Press the back arrow to the Worker's overview. Your address is shown there, like https://searchnet.yourname.workers.dev. If the overview shows "Preview URL" instead, press Visit and copy the address bar.

Check it works — paste it below and press TEST. It should answer with "worker": "searchnet" and its version.

6

Tell the app

Back in SEARCH//NET open SOURCES, paste the address into Your Cloudflare Worker and save. The first-run guide has the same box. From then on every topic you create collects through your Worker.

7

Optional: lock it to you

Anyone who learns the address could spend your free requests. To prevent that: Worker → Settings → Variables and Secrets → Add → type Secret, name SEARCHNET_SECRET, value = any long random string → Deploy. Put the same string in the app next to the Worker address (it's sent as the X-SN-Key header).

UPDATING LATER

The app and the Worker grow together. When the app needs something newer than your Worker has, it tells you ("Your Worker is older than this app"). To update: copy the code above again → Worker → Edit code → select all, paste, Deploy. Your address and secret stay the same. The TEST box above shows which version you're running.

wrangler secret put SEARCHNET_SECRET   # optional, step 7

WHAT IT CAN AND CAN'T DO

sourceneedsnotes
mastodoninstance (e.g. mastodon.social)hashtag timelines; also bridged Bluesky and Loops/Pixelfed video
bluesky–public post search, author feeds, follow lists
reddit–works from the Cloudflare edge even when a home IP is blocked
lemmyinstance (e.g. lemmy.world)federated Reddit-like
youtube–via public Invidious instances (best effort — they come and go)
rssurlany RSS/Atom feed, incl. a YouTube channel's feeds/videos.xml

It cannot run yt-dlp or ffmpeg, so it returns metadata and direct media links where sites expose them — not downloaded files, and no X/Twitter or TikTok (those need a login). For that, run the optional PC server; you can use both at once.

API, for the curious 
GET /health
GET /search?source=mastodon&q=skate&limit=30&instance=mastodon.social[&media=all]
GET /account?platform=bluesky&handle=name.bsky.social&limit=50
GET /follows?platform=mastodon&handle=name@server&instance=mastodon.social
GET /resolve?url=…      best-effort direct media URL
GET /fetch?url=…        CORS proxy

All responses carry permissive CORS headers so the hosted app can call them; add ?key= or the X-SN-Key header when a secret is set.
